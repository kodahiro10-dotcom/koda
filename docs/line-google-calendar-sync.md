# LINEカレンダーとGoogleカレンダーの連携ガイド

## 前提

LINEカレンダーには、外部サービス（Googleカレンダーなど）と直接連携するための公開APIは存在しません。
一方でLINEカレンダーは、スマートフォンの **OS標準カレンダー**（iOSの「カレンダー」/ Androidの「Googleカレンダー」）に登録された予定を自動的に読み込んで表示する機能を持っています。

そのため、以下の手順で **Googleカレンダー → OS標準カレンダー → LINEカレンダー** という経路を作ることで、コードを書かずに連携を実現できます。

```
Googleカレンダー
      │  (アカウント同期)
      ▼
OS標準カレンダー（iOS/Android）
      │  (LINEアプリのカレンダー権限)
      ▼
LINEカレンダー（「すべてのカレンダー」に表示）
```

> 注意: この方法は **Googleカレンダー → LINEカレンダーへの片方向の表示連携** です。
> LINEカレンダーで新規作成した予定がGoogleカレンダーへ自動で書き戻されることはありません。

---

## iOSの場合

1. **設定アプリ** → **カレンダー** → **アカウント** を開く
2. **アカウントを追加** → **Google** を選択し、連携したいGoogleアカウントでログイン
3. 表示された項目のうち **カレンダー** のトグルをオンにする
4. LINEアプリを開き、**ホームタブ** → 右上の設定（歯車） → **カレンダー** を開く
5. **カレンダーとの同期** または **端末のカレンダーを表示** の項目をオンにする
   （iOSの「カレンダーへのアクセス」許可を求められたら「許可」を選択）
6. LINEカレンダーの「すべてのカレンダー」画面にGoogleカレンダーの予定が表示されることを確認する

---

## Androidの場合

1. **設定アプリ** → **アカウント**（または「パスワードとアカウント」） を開く
2. 連携したいGoogleアカウントが追加済みか確認し、未追加なら **アカウントを追加** → **Google** で追加
3. 追加済みアカウントを開き、**アカウントの同期** から **カレンダー** の同期をオンにする
4. LINEアプリを開き、**ホームタブ** → 右上の設定（歯車） → **カレンダー** を開く
5. **端末のカレンダーへのアクセス** を許可し、同期対象としてGoogleカレンダーを選択する
6. LINEカレンダーの「すべてのカレンダー」画面にGoogleカレンダーの予定が表示されることを確認する

---

## 反映されない場合の確認事項

- LINEアプリのバージョンが **26.3.0以上** であること
- 端末の設定で、LINEアプリに **カレンダーへのアクセス権限** が許可されていること
  （iOS: 設定 → LINE → カレンダー / Android: 設定 → アプリ → LINE → 権限 → カレンダー）
- Googleカレンダー側で対象のカレンダーが表示（チェックオン）になっていること
- 同期には数分かかる場合があるため、時間をおいて再確認する

## 制限事項

- LINEカレンダー独自の「共有カレンダー」（トークルームごとの予定）は、この手順の対象外です。個人の予定・OS標準カレンダーに登録された予定のみが連携対象です。
- Googleカレンダー側で予定を編集・削除した場合、OS標準カレンダー経由で再同期されるまでLINEカレンダー側の表示は更新されません。
- LINEカレンダー側で作成した予定はGoogleカレンダーへ自動反映されません（片方向連携のため）。
