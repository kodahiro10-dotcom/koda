# 転職活動スケジュール管理

転職活動中の面接日程・書類提出期限をまとめて管理する、ブラウザだけで動くWebアプリです。
サーバー不要で、データはブラウザのlocalStorageに保存されます。

## 主な機能

- 企業名・種別（書類提出／面接／オファー回答など）・日時・メモを登録
- 期限超過／3日以内／それ以降を色分け表示
- 未対応・完了・すべてで絞り込み
- 期限が近い予定をまとめて表示するリマインダー欄

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
npm run lint     # oxlintによるチェック
```
